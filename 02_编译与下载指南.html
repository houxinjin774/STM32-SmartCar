🛠 02 编译与下载指南

目标：把 Project\ 里的工程在 Keil5 里编译成功，并烧录进 STM32F103C8T6。工程里所有选项（芯片型号、宏定义、头文件路径、MicroLIB、生成HEX）都已经配好了，正常情况下你只需要打开 → 编译 → 下载。

一、你需要准备什么

软件说明
Keil MDK5（任意 5.x 版本）装好后要装 STM32F1xx 器件包：Keil 菜单 Pack Installer → 搜 STM32F1xx_DFP → Install（需要网络）
ARM Compiler 5MDK 5.36 及以前自带；MDK 5.37 以后不带，安装时勾选或单独装（报错见 FAQ）
ST-Link 驱动ST 官网下载 STSW-LINK007，或插上 ST-Link 后用驱动精灵装
ST-Link 调试器 + 4 根杜邦线淘宝几块钱~十几块

二、打开工程

1双击 Project\SmartCar.uvprojx（这就是 MDK5 新格式工程，已经迁移并实测编译通过）。
2如果你打开的是旧的 SmartCar.uvproj，会弹窗 Using an MDK Version 4 Project 问你怎么处理：点 "Migrate to Device Pack"（迁移到器件包）→ 弹出"Migration completed"点确定。这是正常的一次性格式升级，迁移后会多出一个 SmartCar.uvprojx，以后用它就行。
3迁移过程中如果闪过一次 Error: Device not found，点确定关掉即可（迁移器会自动完成器件映射，已实测无影响）。
4左侧 Project 窗口应能看到 4 个分组：User / Hardware / CMSIS / StdPeriph。

三、编译

✅ 本工程已经在 Keil MDK5（AC5.06 编译器）实际编译通过：0 错误、0 警告，并且 Project\Objects\SmartCar.hex 已经生成——不想折腾编译的话，可以直接用 Keil（Flash → Download）或 ST-Link Utility 烧录这个 hex。程序大小约 7.5KB（芯片有 64KB，非常宽裕）。
1点工具栏的编译按钮，或按 F7（Rebuild 用 F7 前先 Project → Clean）。
2等下方 Build Output 显示：
"SmartCar.axf" - 0 Error(s), x Warning(s).
（0 个错误就成功了，几个警告不影响使用）
3编译成功后 Project\Objects\ 里会生成 SmartCar.hex（工程已配置自动生成 HEX）。
常见编译报错：
① Error: L6218E: Undefined symbol ... → 检查 StdPeriph 组里的文件是否都在。
② cannot open source file stm32f10x.h → 头文件路径丢了：Options → C/C++ → Include Paths 填 .\User;.\Hardware;.\Core;.\StdPeriph\inc
③ No Compiler 5 / ARMCC not found → 你装的是新版 MDK，需要另装 ARM Compiler 5（见 FAQ）。

四、下载（烧录）到单片机

1用杜邦线把 ST-Link 和最小系统板连好（3.3V、GND、SWDIO、SWCLK，见 01 接线指南第八节）。两个 BOOT 跳线帽都在 0 档。
2Keil 里点魔术棒 Options for Target → Debug 标签 → 右侧下拉框选 ST-Link Debugger → 点 Settings：应能看到 SW Device 信息（有 SN 号和芯片 ID 说明连上了）。
3再到 Utilities 标签：勾选 Use Debug Driver（与 Debug 页一致），点 Settings：确认 Flash Download 页里有 STM32F10x Med-density flash 128K，并勾选 Reset and Run（下载完自动运行）。
4按 F8（或 Flash → Download）。成功会显示 Application running ...。此时小车上电后板载 LED 会每 0.5 秒闪一下（心跳）。
下载失败排查：
① No target connected → 检查 4 根线；确认最小系统板有电（可只靠 ST-Link 的 3.3V 供电）
② No Algorithm found / Flash load failed → Utilities → Settings → Add → 选 STM32F10x Med-density flash (128K)
③ 一直连不上 → 按住板上的 RESET 再点下载，瞬间松开；或把 BOOT0 拨到 1 连接后拨回 0
④ ST-Link 插上电脑没反应 → 装 STSW-LINK007 驱动

五、（备用）手动新建工程的完整步骤

如果 SmartCar.uvproj 因版本问题实在打不开，按下面步骤 5 分钟就能手动建一个一模一样的（前提：库文件都在 Project 文件夹里）：

步骤操作
1Project → New uVision Project，保存到 Project 文件夹，命名 SmartCar
2器件选择：STMicroelectronics → STM32F1 Series → STM32F103C8
3弹出的 Manage Run-Time Environment 直接点 Cancel（我们手动加文件）
4左侧 Targets→Source Group 1 改名为 User，右键 Add Existing Files，加 User\main.c、User\stm32f10x_it.c
5同样新建分组 Hardware，加 Hardware 里的 6 个 .c；新建 CMSIS，加 Core\core_cm3.c、Core\system_stm32f10x.c、Core\startup_stm32f10x_md.s；新建 StdPeriph，加 StdPeriph\src 里的 misc.c、stm32f10x_gpio.c、stm32f10x_rcc.c、stm32f10x_tim.c、stm32f10x_exti.c、stm32f10x_usart.c、stm32f10x_flash.c
6魔术棒 → Target 页：晶振 8MHz（默认即可）
7C/C++ 页：Preprocessor Symbols 的 Define 填 USE_STDPERIPH_DRIVER,STM32F10X_MD；Include Paths 填 .\User;.\Hardware;.\Core;.\StdPeriph\inc；勾选 Use MicroLIB
8Output 页：勾选 Create HEX File
9Debug 页选 ST-Link Debugger；Utilities 页勾 Use Debug Driver，Settings 里确认 Flash 算法为 STM32F10x Med-density 128K
10F7 编译 → F8 下载

六、日常修改代码的流程

改 .c/.h 文件（用 Keil 自带编辑器，中文注释正常显示）→ F7 编译 → F8 下载 → 观察现象。常用参数都在 Project\User\config.h 里，比如循迹速度 TRACK_BASE、避障距离 AVOID_DIST_CM、三档速度等，改完重新编译下载即可。

提示：如果你在这台电脑还没装 Keil5，先去安装（官网或正规渠道），再回来做本章操作。
