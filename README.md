# STM32-SmartCar 🚗

基于 **STM32F103C8T6 最小系统板** 的四驱智能小车，使用 **ST 标准外设库（SPL V3.5.0）+ Keil MDK** 开发，代码全部中文注释，适合入门学习。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 📱 蓝牙遥控 | HC-05 + 手机蓝牙串口 APP，前后左右 + 三档调速 |
| ⚫ 循迹行驶 | 3 路 TCRT5000 沿黑线自动行驶，丢线自动找线 |
| 🧱 自动避障 | 3 路红外探头 + HC-SR04 超声波，遇障后退绕行 |
| 📏 测速测距 | 4 路编码器测速/里程，超声波测距，手机实时查看 |
| 🔧 传感器监视 | 手机上实时打印全部传感器数值，方便校准 |

## 🧰 硬件清单

- STM32F103C8T6 最小系统板（Blue Pill）
- TB6612 电机驱动模块 ×1（左/右各 2 个 TT 减速电机并联）
- TCRT5000 循迹模块 ×3、红外避障模块 ×3
- HC-SR04 超声波 ×1、HC-05 蓝牙 ×1
- LM2596S 降压模块 ×1（电池 7.4V → 5V 给单片机与传感器供电，电机直接吃电池）
- 光电编码器 ×4（码盘 + 槽型传感器）
- 18650 电池 ×2（串联）

## 🚀 快速上手

1. 双击 `01_接线指南.html` 照表接线（⚠️ 所有 GND 共地；LM2596 先用万用表调到 5.00V 再接单片机）
2. 用 Keil5 打开 `Project\SmartCar.uvprojx`，F7 编译、F8 烧录（或直接烧 `Objects\SmartCar.hex`）
3. 手机蓝牙配对 HC-05（密码 1234），装蓝牙面板 APP 当遥控器（见 `04_手机遥控面板教程.html`），或用蓝牙串口 APP 发 `H` 查看帮助

## 📱 蓝牙指令

```
1=遥控  2=循迹  3=避障  4=传感器监视  0=停止
F前 B后 L左 R右 S停   +/- 调速
D=测距  V=测速  T=打印传感器  H=帮助
```
