三、快速上手 5 步走

1接线 —— 照着 01_接线指南.html 一根一根接。接完对着文末的检查清单打勾。
2调电源 —— 先不接单片机，给电池上电，用万用表把 LM2596 的输出调到 5.00V（这一步千万别跳过，详见接线指南）。
3烧录 —— 照着 02_编译与下载指南.html 打开 Project\SmartCar.uvprojx，编译（F7），用 ST-Link 下载（F8）。工程已在你电脑的 Keil 上实测编译通过（0 错误 0 警告），Project\Objects\SmartCar.hex 现成的，跳过编译直接烧也行。
4连蓝牙 —— 手机配对 HC-05（密码 1234），照 04_手机遥控面板教程.html 装一个遥控面板 APP，就能用按钮开车；发 H 能收到帮助信息也说明链路通了。
5调试跑车 —— 照着 03_调试指南与常见问题.html：先架空测电机，再校准循迹，最后下地跑。

五、开始之前必须知道的 4 件事

⚠️ 共地！ 电池、LM2596、单片机、TB6612、所有模块的 GND 必须全部连在一起。不共地 = 信号全乱、车乱跑、模块全都不工作。这是新手翻车第一名。
⚠️ 先调压再上电！ LM2596 出厂时输出电压是随机的（可能 10V），必须先用万用表调到 5.00V，再接单片机。接错可能烧板子。
🔋 两节 18650 串联是 7.4V~8.4V，直接给 TT 电机（额定 6V）会跑得很快、发热明显。本工程已在代码里限制了最高速度，一般没问题；如果电机烫手，把 config.h 里的速度参数调小。
🔌 下载程序用 ST-Link 接 SWD 四根线（3.3V、GND、SWDIO、SWCLK），两个 BOOT 跳线帽都插在 0 档（靠外的位置）。
